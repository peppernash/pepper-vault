## Review Protocol

Every 4 hours during active time:
1. **Review completed tasks** - What was delivered?
2. **Check quality** - Did outputs meet standards?
3. **Assess efficiency** - Were timings reasonable?
4. **Identify patterns** - What's working/failing consistently?
5. **Log adjustments** - What to change for next cycle?

### Quality Checks
- Voice compliance: Did content sound like Steve?
- Data accuracy: Were all stats verified?
- Template adherence: Did structure match requirements?
- Dependency flow: Did agents wait for prerequisites?

### Efficiency Checks
- Cron timing: Are schedules realistic?
- Resource usage: Any bottlenecks?
- Blocking issues: What caused delays?
- Communication: Were handoffs clear?

### Pattern Recognition
- Recurring errors → Add to lessons.md
- Consistent successes → Document in MEMORY.md
- Process improvements → Update skill files
- System issues → Flag for maintenance
