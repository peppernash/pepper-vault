# Getting Started with Pepper Vault

Welcome to your new Obsidian knowledge management system!

## First Steps

1. **Open Obsidian** and point it to: `~/Documents/Pepper`
2. **Create your first daily note**: Cmd/Ctrl + P → "Open today's daily note"
3. **Try templates**: Cmd/Ctrl + P → "Templates: Insert template"

## Key Features Configured

- **Daily Notes**: Auto-created in `01 - Daily Notes` with template
- **Templates**: Available for projects, meetings, and daily notes
- **New files**: Default to `00 - Inbox` for quick capture
- **Attachments**: Auto-organized in `99 - Meta/Attachments`

## Workflow Suggestions

1. **Quick Capture**: Drop new notes in `00 - Inbox`, organize later
2. **Daily Ritual**: Use daily notes for planning and reflection
3. **Projects**: Use project template for both work and personal projects
4. **Linking**: Use `[[Note Name]]` to create connections between notes
